# Class Board Instrument

Project 3 of *Basic Skills for Experimentalists* (TIGP 2026): the class board as an instrument, its housing, firmware and app.

- **Project website:** https://lihdong02.github.io/class-board-instrument/ (`index.html`, pictures in `images/`)
- **Housing:** `housing/` — `housing.scad` (OpenSCAD 2021.01) and the print files; the working copy, which opens with
  the board meshes in place, is in [class-board-2026 / docs/students/lihdong/housing](https://github.com/TIGP-Experimental-Methods/class-board-2026/tree/w3-lihdong/docs/students/lihdong/housing)
- **Pictures:** `tools/make_renders.sh` re-renders `images/` from the housing model
- **The board:** https://github.com/TIGP-Experimental-Methods/class-board-2026

Work in progress: firmware and app to follow.
